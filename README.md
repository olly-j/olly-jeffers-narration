# Olly Jeffers — audiobook narrator

Production website for London-based British audiobook narrator Olly Jeffers.

## Publication

The site is deliberately dependency-free and is published from the repository root with GitHub Pages.

## Content policy

Only confirmed launch information appears publicly. Unfinished sample plans, speculative credits, private contact details and other non-launch material are intentionally excluded.

Every photograph is a verified image of Olly Jeffers. Assets are stored locally to prevent third-party availability from breaking the page.

- `olly-jeffers-black-tie.jpg` and its responsive WebP variants: high-resolution photograph supplied directly by Olly for the hero and social preview.
- `olly-jeffers-waterfront.jpg` and its responsive WebP variants: high-resolution personal photograph supplied directly by Olly. The second person’s teal shoulder was removed at Olly’s request; Olly’s identity, striped shirt, pose and the rest of the original scene were preserved.

No synthetic likenesses or stock portraits are used.
